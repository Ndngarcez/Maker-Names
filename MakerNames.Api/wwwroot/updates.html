MakerNames

Updates

Follow the latest MakerNames improvements. We update this page when new editor features, export tools, account changes, or production fixes go live.

June 16, 2026

Download Notifications

  • Added internal email notifications when someone downloads a SVG, DXF, STL or full pack from MakerNames.
  • Download emails include the file name, format, account status and page that started the download.
  • Duplicate notifications are avoided when the same temporary download link is opened twice for the same format.
June 6, 2026

Image Import STL Modes

  • Added image import STL modes for Outline, Silhouette and Cookie cutter exports.
  • Kept imported coloring-page drawings open by default so windows, wheels and other holes are not filled accidentally.
  • Added a taller cookie-cutter export mode that preserves outline openings for cutter-style STL files.
  • Fixed the STL exporter so Outline, Silhouette and Cookie cutter now generate genuinely different 3D geometry.
June 5, 2026

Mobile Editor Polish

  • Hid the community renders section from the homepage while the gallery is still empty.
  • Added a mobile zoom bar above the canvas with Menos, Zoom and Mais controls.
  • Increased the opening zoom on mobile and tablet so designs start much closer.
  • Changed the mobile editor rail to clearer icon-based tool buttons for text, move, spacing, base, accessories and files.
  • Protected the MakerNames brand name from automatic browser translation while keeping the rest of the site translatable.
  • Added multi-accessory support so several SVG, DXF or image accessories can sit on the same design, each with its own selection, movement, scale, rotation and color.
  • Changed image search to open a browser image search for coloring-page style artwork instead of showing Openverse results inside the editor.
June 4, 2026

Editor Default View

  • Changed the desktop editor opening zoom to 420% so new designs start larger and easier to inspect.
  • Raised the mobile and tablet opening zoom proportionally so the preview starts closer on smaller screens too.
  • Added a Topos de bolo accessory category with SVG bases that include cake stakes for topper designs.
  • Added a password visibility toggle to the account modal for signup, login and password reset.
  • Fixed the preview centering at high opening zoom so names stay visually centered in the canvas.
June 3, 2026

Multi-Name Canvas Tools

  • Added saved names so a finished name can be moved, rotated and scaled as one object.
  • Added support for building designs with multiple names before exporting SVG, DXF and STL packs.
  • Made accessory scale buttons more precise for small placement adjustments.
  • Fixed saved-name previews so letter holes stay open, support lines are not carried into saved names, and moving a saved name keeps the preview camera stable.
  • Fixed saved-name letter junctions so overlapping cursive strokes stay filled in 2D and 3D exports.
  • Improved accessory imports so large SVG, DXF and image accessories auto-fit below the name height without moving the preview camera.
  • Kept the preview camera locked while typing or changing the active name, so zoom and framing stay under the user's control.
  • Improved 3D Preview lighting so multi-name designs stay bright instead of becoming too dark.
  • Added more 3D Preview material styles: matte, acrylic, silver, ceramic and black acrylic.
  • Refined 3D render shading so inverted STL triangles no longer turn the design black and internal mesh lines are much less visible.
  • Added the first community renders system with top liked designs on the homepage and a public gallery page for likes.
  • Added community SVG accessories: imported SVGs and converted outline images can now be saved into the shared accessory library with STL verified, 3D review or 2D-only labels.
June 2, 2026

Signup Notifications and Launch Polishing

  • Added internal email notifications when a new MakerNames account is created.
  • Replaced the old checkout cards with an optional donation/support flow.
  • Changed free downloads so visitors watch a short sponsor video while signed-in accounts can download without the video.
June 1, 2026

Image Search, Font Import and Accessory Tools

  • Added image search and image import tools for turning outline-style images into accessories.
  • Added user font imports with a licence notice before shared fonts are used by others.
  • Added individual accessory color controls, quick accessory previews and reset tools.
  • Improved the default editor setup with a ready-to-use name, font, spacing and pink color.
May 31, 2026

3D Preview Improvements

  • Added a dedicated 3D Preview view for checking STL-style depth before download.
  • Added material options including plastic, gold, neon, wood and metal preview styles.
  • Added a Generate render option for creating a cleaner presentation image from the 3D preview.
  • Improved model lighting, depth shading and drag-to-rotate interaction.
May 30, 2026

Mobile Editor and Accessory Library

  • Reworked the mobile and tablet editor layout with compact tool buttons.
  • Added mobile accessory movement controls for more predictable placement on touch devices.
  • Expanded the accessory library with categories and searchable SVG assets.
  • Added better support for SVG, DXF and STL pack creation from the main editor.

Public Site, SEO and Account Setup

  • Published MakerNames on the custom domain makernames.app.
  • Added Privacy Policy, Terms, About, Contact and How It Works pages.
