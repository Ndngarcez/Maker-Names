MakerNames

How MakerNames Works

MakerNames helps you create custom name files for CNC, laser cutting and 3D printing without rebuilding every design by hand.

1. Type a Name or Import a TXT List

Start with a single name or upload a TXT batch list. MakerNames can move through names one by one so you can prepare a full set of files faster.

2. Choose a Font and Connect the Letters

Select a maker-friendly font, connect letters for cleaner cuts, and adjust spacing until the name looks right for your material and project.

3. Add a Support Line or Accessory

Add a support line for connected name signs, or place an SVG accessory from the library to create more complete designs for gifts, plaques and workshop products.

4. Export SVG, DXF and STL

Download production-ready SVG, DXF and STL packs for laser cutters, CNC routers, vinyl cutters, design software and 3D printing workflows.

Who Uses It

MakerNames is useful for crafters, laser businesses, CNC users, 3D printing creators, sign makers and small workshops that need repeatable custom name designs.
